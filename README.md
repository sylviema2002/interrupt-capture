# 中断快记

中断快记由马骁艺设计并发起，基于真实工作流需求，通过 Codex 辅助迭代开发。

中断快记是一个轻量浏览器插件：当你正在浏览器里处理飞书文档、网页资料或其他工作时，如果突然被打断，只需要写一句话，它会记录当前页面来源、按你设置的时间提醒你回来，并把记录同步到飞书多维表格。

它适合这种场景：事情很多、切换频繁、经常被临时消息或紧急事项打断，回来以后容易忘记“刚刚做到哪了”。

## 主要功能

- 一句话记录中断事项。
- 自动抓取当前 Chrome 标签页标题和链接。
- 默认 15 分钟提醒，也可以在右上角“设置”里改成自己的默认时间。
- 单条事项可以点击“稍后提醒”，临时改成 15 分钟后、1 小时后、明天 9 点或自定义时间。
- 提醒时只弹出屏幕中间的独立窗口，不再弹右下角系统通知。
- 提醒窗口默认在屏幕中间打开，并会尝试回到前台。
- 同一事项只保留一个提醒窗口，不会越堆越多。
- 支持“再等 X 分钟”“稍后提醒”“暂停”“恢复计时”“回来了/完成”。
- 写入飞书多维表格，记录未完成、已完成、暂停和完成时间。
- 完成后从插件本地删除，减少本地长期占用。
- 本地版主界面可复制未完成事项；设置里可低频导出全部数据，也可手动清理已完成记录。
- 设置里提供“提交反馈”，方便用户主动反馈问题和使用场景。

## 项目结构

```text
interrupt-capture-extension/
  manifest.json                 Chrome 插件配置
  popup.html / popup.js          插件弹窗
  reminder.html / reminder.js    强提醒窗口
  background.js                  提醒、窗口、同步调度
  feishu-sync-service.js         本地飞书同步服务
  sync-config.example.json       飞书同步示例配置
  base-fields.json               多维表格字段示例
interrupt-capture-local-only/
  本地版插件，不连接飞书，只保存到浏览器本地并支持导出 TXT
dist/
  interrupt-capture-feishu-cli.zip
  interrupt-capture-local-only.zip
```

## 两个版本怎么选

| 版本 | 数据保存位置 | 适合谁 |
| --- | --- | --- |
| 飞书同步版 | 浏览器本地 + 你的飞书多维表格；完成后从插件本地删除 | 已有飞书 CLI、Codex 或其他 AI 助手的人 |
| 本地版 | 只保存在浏览器本地，可导出 TXT | 没有飞书 CLI、没有 AI 工具、只想手动安装的人 |

## 使用前准备

- Chrome 浏览器，或其他兼容 Chrome 扩展的浏览器。
- Node.js，用来运行本地同步服务。
- lark-cli，并完成飞书账号登录。
- 一个飞书多维表格，用来接收记录。

## 快速开始

### 飞书同步版

最推荐的用法是：把 GitHub 地址直接发给 Codex、Claude Code、Cursor 等 AI 助手，让它帮你把项目文件下载到电脑里、配置和安装。

GitHub 地址：

```text
https://github.com/sylviema2002/interrupt-capture
```

给 AI 的提示词：

```text
请帮我从这个 GitHub 项目安装并配置“中断快记”飞书同步版 Chrome 插件：https://github.com/sylviema2002/interrupt-capture 。请你把项目文件下载到我的电脑里，使用 interrupt-capture-extension 这个插件文件夹。如果我还没有飞书多维表格，请帮我新建一张“中断快记”表；如果我已经有表，请帮我检查字段是否齐全。表里需要这些字段：内容、来源标题、来源链接、状态、记录时间、完成时间、插件记录ID。请帮我从飞书表格链接里识别 baseToken 和 tableId，填进 sync-config.json。baseToken 是飞书多维表格这个文件的编号，tableId 是里面某一张表的编号。请根据 sync-config.example.json 在同一个文件夹里新建 sync-config.json，不要直接改名覆盖示例文件。然后启动 start-sync-service.cmd，指导我在 Chrome 或 Edge 扩展程序里加载 interrupt-capture-extension 文件夹，最后测试提醒和写入飞书是否正常。注意：sync-config.json 是我的私人配置，不要上传、公开或发给别人。
```

人工安装只作为备用：

1. 下载或克隆本项目。
2. 进入 `interrupt-capture-extension` 文件夹。
3. 在这个文件夹里复制一份 `sync-config.example.json`，粘贴在同一个文件夹，然后把复制出来的新文件改名为 `sync-config.json`。
4. 在 `sync-config.json` 里填入自己的飞书多维表格信息：`baseToken` 是多维表格文件编号，`tableId` 是表格里某一张表的编号。
5. 把 `serviceToken` 改成一串只有自己知道的随机字符。它只用于插件和本机同步服务之间互相确认身份，不是飞书 token，也不会产生 Codex 费用。
6. 双击 `start-sync-service.cmd`，保持窗口打开。
7. 打开 Chrome 扩展程序页面：`chrome://extensions/`。
8. 开启“开发者模式”。
9. 点击“加载已解压的扩展程序”，选择 `interrupt-capture-extension` 文件夹。
10. 点插件图标，写一句中断事项，点击“记一下，X 分钟后提醒”。

右上角“设置”可以修改默认提醒时间。这个设置只影响之后新增的事项；已经记录的事项可以在对应卡片上点“稍后提醒”临时调整。

设置里的“提交反馈”会直接打开 GitHub Issue 页面，并自动带上反馈模板。

### 本地版

本地版不连接飞书，日常记录存在插件里。主界面的“复制未完成”只复制当前未完成事项，适合发给别人或发给自己；设置里的“导出全部数据”用于低频备份全部记录。已完成事项不会继续提醒，也不会显示在待办列表里，但会保留在导出记录中，直到你在设置里点击“清理已完成”。

1. 解压 `dist/interrupt-capture-local-only.zip`。
2. 打开 Chrome 或 Edge 的扩展程序页面。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `interrupt-capture-local-only` 文件夹。
5. 点插件图标，先点“测试提醒”。
6. 写一句中断事项，点击“记一下，X 分钟后提醒”。
7. 需要备份时，打开右上角设置，点击“导出全部数据”可生成 `.txt` 文件，用电脑自带记事本打开。

右上角“设置”可以修改默认提醒时间。每条事项也可以单独点“稍后提醒”，临时改成 15 分钟后、1 小时后、明天 9 点或自定义时间。

设置里的“提交反馈”会直接打开 GitHub Issue 页面，并自动带上反馈模板。

## 更新方式

已安装过插件的用户，不需要重新注册或登录。下载新版安装包并替换原插件文件后，打开浏览器扩展程序页面，点击这个插件卡片上的“重新加载”或“刷新”即可使用新版。

版本更新记录见 `CHANGELOG.md`。

## 飞书多维表格字段

建议建一张表，包含这些字段：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| 内容 | 文本 | 记录这次中断的事 |
| 来源标题 | 文本 | 自动抓取当前网页标题 |
| 来源链接 | URL | 自动抓取当前网页链接 |
| 状态 | 单选 | 未完成、已完成、暂停 |
| 记录时间 | 日期时间 | 创建记录的时间 |
| 完成时间 | 日期时间 | 点“回来了/完成”的时间 |
| 插件记录ID | 文本 | 用来匹配插件本地记录和飞书记录 |

也可以参考 `interrupt-capture-extension/base-fields.json`。

## 常见问题

### 插件提示 Failed to fetch

通常是本地同步服务没有启动。请先双击 `interrupt-capture-extension/start-sync-service.cmd`，再重新点击插件按钮。

### 写入飞书失败

优先检查三件事：

- `sync-config.json` 里的 `baseToken` 和 `tableId` 是否正确。
- `sync-config.json` 里的 `serviceToken` 是否已经从示例占位符改成自己的随机字符。
- lark-cli 是否已经登录飞书账号。
- 多维表格字段名是否和上面的字段一致。

### 提醒没有弹出来

先点击插件里的“测试提醒”。如果测试也没有弹窗，请重新加载扩展程序，或检查浏览器是否允许插件弹出独立窗口。

### 可以不用飞书吗

可以。使用 `interrupt-capture-local-only` 本地版即可。它只保存在浏览器本地，不写入飞书。

### 为什么本地版不直接写电脑文件

浏览器插件默认不能悄悄写入电脑任意文件，这是浏览器的安全限制。要自动写本地文件，需要额外安装本地服务，反而会变重。本地版选择更轻的方式：日常存在插件里，需要备份时一键导出 TXT。

## 隐私说明

插件默认不上传个人记录到作者或第三方服务器。

- 飞书同步版会把你主动记录的中断事项写入你自己配置的飞书多维表格；作者无法看到这些记录。
- 本地版只把记录保存在你的浏览器本地，除非你自己点击“导出全部数据”生成 TXT 文件。
- 插件只读取当前活动标签页的标题和链接，不读取网页正文。
- `sync-config.json` 里含有你的飞书表格配置和本地服务口令，请不要提交到公开仓库。
