# 中断快记（本地版）

中断快记由马骁艺设计并发起。Copyright (c) 2026 马骁艺，MIT License。

这个版本适合没有飞书 CLI、也没有 AI 助手协助配置的用户。

它不写入飞书，只把中断事项保存在浏览器本地。主界面的“复制未完成”只复制当前未完成事项，适合发给别人或发给自己；设置里的“导出全部数据”会生成一个 `.txt` 文件，用户可以用电脑自带记事本打开。

隐私说明：本地版默认不上传个人记录。

## 适用浏览器

- Google Chrome
- Microsoft Edge
- 其他支持 Chrome 扩展的 Chromium 浏览器

Safari 和 Firefox 暂不支持本安装包。

## 安装方式

1. 解压安装包。
2. 打开 Chrome 或 Edge 的扩展程序页面。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后能直接看到 `manifest.json` 的那个文件夹。
6. 点击插件图标，先点“测试提醒”。
7. 能看到提醒窗口后，就可以开始记录。

右上角“设置”可以手填默认提醒时间；每条事项也可以点“稍后提醒”，临时改成 15 分钟后、1 小时后、明天 9 点；自定义分钟用手填，自定义日期时间用系统日期和时间控件。

## 数据保存在哪里

记录保存在浏览器自己的本地扩展存储里。卸载插件、清理浏览器数据或换电脑，都可能导致本地记录丢失。

已完成事项不会继续提醒，也不会显示在待办列表里，但会保留在浏览器本地，方便之后导出留痕。

建议定期在设置里点击“导出全部数据”，把全部记录导出成 `.txt` 文件备份。需要减轻浏览器本地存储时，可以点击“清理已完成”，此刻之前的已完成记录会从浏览器删除；之后再导出全部数据，会从清理后保留和新增的数据开始导出。
