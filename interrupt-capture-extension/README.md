# 中断快记飞书同步版

这是中断快记的飞书同步版插件源码目录。完整开源说明见项目根目录的 `README.md`。

中断快记由马骁艺设计并发起。Copyright (c) 2026 马骁艺，MIT License。

隐私说明：飞书同步版只会把你主动记录的事项写入你自己配置的飞书多维表格和飞书日程，不会上传给作者或第三方服务器。

## 当前版本

1.0.4

## 核心能力

- 一句话记录当前被打断的工作。
- 自动读取当前标签页标题和链接，不读取网页正文。
- 三类任务：中断任务、规划任务、待安排。
- 没有跨日信息时归入中断任务，按默认间隔循环强提醒。
- 明确说出“明天”“后天”或具体日期时归入规划任务，并自动创建飞书日程。
- 支持自然语言时间点和时间段。
- 支持配合 Windows `Win + H` 语音输入；文本完整后自动写入。
- Windows 本机辅助程序会托管飞书同步服务，并帮助提醒窗口保持置顶。
- 删除已关联日程的任务时，会同步删除飞书日程，并把飞书表格状态改为“已删除”。

## 快速使用

1. 先把 `sync-config.example.json` 复制成 `sync-config.json`。
2. 在 `sync-config.json` 里填入自己的飞书多维表格 `baseToken` 和 `tableId`。
3. 把 `serviceToken` 改成一串只有自己知道的随机字符。它只用于插件和本机同步服务之间互相确认身份。
4. 双击运行 `start-sync-service.cmd`。
5. 打开 Chrome 或 Edge 扩展程序页面，开启“开发者模式”。
6. 点击“加载已解压的扩展程序”，选择本文件夹。
7. 在浏览器里点插件图标，先点“测试提醒”。

## 飞书字段

插件会尽量自动补齐缺失字段。建议表格包含：

- 内容
- 来源标题
- 来源链接
- 状态：未完成、已完成、暂停、已删除
- 记录时间
- 完成时间
- 插件记录ID
- 任务类型
- 日程开始时间
- 日程结束时间
- 日程状态

可以参考 `base-fields.json` 创建字段。
