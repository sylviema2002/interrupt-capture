# 中断快记 Chrome 插件

这是插件源码目录。完整开源说明见项目根目录的 `README.md`。

中断快记由马骁艺设计并发起。Copyright (c) 2026 马骁艺，MIT License。

隐私说明：飞书同步版只会把你主动记录的事项写入你自己配置的飞书多维表格，不会上传给作者或第三方服务器。

## 快速使用

1. 先把 `sync-config.example.json` 复制成 `sync-config.json`。
2. 在 `sync-config.json` 里填入自己的飞书多维表格 `baseToken` 和 `tableId`。
3. 把 `serviceToken` 改成一串只有自己知道的随机字符。它只用于插件和本机同步服务之间互相确认身份。
4. 双击运行 `start-sync-service.cmd`，保持这个窗口打开。
5. 打开 Chrome 扩展程序页面，开启“开发者模式”。
6. 点击“加载已解压的扩展程序”，选择本文件夹。
7. 在浏览器里点插件图标，写一句话，点击“记一下，X 分钟后提醒”。

## 本地提醒逻辑

- 默认 15 分钟提醒，可在右上角“设置”里滚动选择。
- 单条事项可点击“稍后提醒”，临时改成 15 分钟后、1 小时后、明天 9 点；自定义分钟用手填，自定义日期时间用系统日期和时间控件。
- 到时间会弹出独立提醒窗口。
- 同一事项不会堆出多个提醒窗口；新的提醒会复用旧窗口。
- 点“回来了/完成”后，会更新飞书状态并从插件本地删除。
- 点“暂停”后不会继续提醒，恢复后按这条事项自己的时间重新计时。
- 暂停事项可以加入飞书日程；可选择日期、开始时间和结束时间，日程标题直接使用事项内容，详情会按行展示来源和记录 ID。
- 打开插件时会低频检查已加入的飞书日程是否仍存在；如果用户在飞书日程里手动删除，插件会提示“飞书日程已被删除”，并允许重新加入。
- 删除事项时会同步删除已关联的飞书日程，并把飞书表格状态改为“已删除”。
- “复制未完成”只复制未完成事项内容，不带来源链接。

## 飞书字段

插件默认写入这些字段：

- 内容
- 来源标题
- 来源链接
- 状态：未完成、已完成、暂停、已删除
- 记录时间
- 完成时间
- 日程开始时间
- 日程结束时间
- 日程状态
- 插件记录ID

可以参考 `base-fields.json` 创建字段。
